Privacy Policy

Effective date: 2026-11-18 · Applies to the LeonidaLoop Studio desktop app (“the App”) and this website.

Español ↓

1. Who we are

LeonidaLoop is an independent fan project about GTA 6. The App is a private tool. Its only user is the LeonidaLoop owner (“we”), who uses it to manage the LeonidaLoop accounts on YouTube and TikTok. The App is not offered to the public, and other people cannot create accounts in it.

2. Data the App receives from TikTok

When the owner connects a LeonidaLoop TikTok account through TikTok Login Kit, the App requests the user.info.basic scope and receives the following, about the owner's own account only:

  • open ID (and union ID, if TikTok provides it);
  • display name;
  • avatar image URL;
  • OAuth access token and refresh token, with their expiry times and granted scopes.

We use this data only to confirm that the correct LeonidaLoop account is connected and to keep the connection active. If uploads are enabled later through TikTok's Content Posting API, the App will send videos the owner has approved to that same account and use the token only for that. We will update this policy before that happens.

3. Data from other platforms

  • YouTube (Google): scope youtube.readonly for the LeonidaLoop channels. The App stores the channel ID, title and handle so it can verify the channel's identity.
  • Public metadata: to find trending topics, the App reads publicly available video and stream metadata (titles, dates, view counts, channel names) from YouTube RSS feeds and the Twitch API. It does not log in to anyone else's account or download their videos.

We do not collect data about the people who watch our videos beyond the aggregate statistics each platform shows to channel owners.

4. Where data is stored

  • Everything stays on the owner's Windows computer. LeonidaLoop has no servers or cloud databases.
  • Tokens and OAuth client credentials are encrypted with Windows DPAPI, so only the owner's Windows user can decrypt them. They are kept in a folder only that user can access. Tokens are never written to logs or shown on screen.
  • Public account identifiers (channel or account ID, name, handle) are kept in a local configuration file.

5. Sharing

We do not sell, rent or share TikTok user data or any other personal data with third parties. We do not use it for advertising, profiling or training AI models. The only data sent out is what each platform's own API needs for an action the owner starts, such as a request to TikTok for profile information.

6. Retention and deletion

  • Tokens are kept while the account is connected. Disconnecting in the App deletes the local token files.
  • Access can also be revoked from TikTok, in the app permissions section under Settings and privacy. For Google, use the Google Account's Third-party apps page.
  • Account identifiers in the local configuration are deleted when the owner removes that account from the configuration.

7. This website

This is a static site hosted on GitHub Pages. It uses no cookies, analytics, ads, trackers or forms, and loads nothing from third parties. GitHub, as the host, may process technical data such as visitors' IP addresses for security and operation, under the GitHub Privacy Statement.

8. Children

The App is used only by the LeonidaLoop owner. Neither the App nor this website is directed at children, and we do not knowingly collect data from them.

9. Security

We protect data with the measures described above: local storage only, DPAPI encryption, restricted folder permissions and minimal scopes. No system is perfectly secure, and we cannot promise absolute security.

10. Changes and contact

We will update this page and its effective date before changing how the App uses data. For questions or requests: contact LeonidaLoop.

Política de privacidad

Vigente desde: 2026-11-18 · Se aplica a la aplicación de escritorio LeonidaLoop Studio («la App») y a este sitio web.

1. Quiénes somos

LeonidaLoop es un proyecto fan independiente sobre GTA 6. La App es una herramienta privada que usa únicamente el propietario de LeonidaLoop para gestionar sus cuentas de YouTube y TikTok. No se ofrece al público.

2. Datos de TikTok

Al conectar una cuenta de TikTok de LeonidaLoop mediante Login Kit (permiso user.info.basic), la App recibe, solo de esa cuenta propia:

  • open ID (y union ID, si TikTok lo facilita);
  • nombre visible;
  • URL del avatar;
  • tokens OAuth con su caducidad y los permisos concedidos.

Se usan solo para comprobar que la cuenta conectada es la correcta y para mantener la conexión. Si más adelante se activa la publicación (Content Posting API), la App enviará solo vídeos aprobados por el propietario a esa misma cuenta. Esta política se actualizará antes de que ocurra.

3. Otras plataformas

  • YouTube: permiso youtube.readonly, para verificar el canal.
  • YouTube RSS y API de Twitch: metadatos públicos (títulos, fechas, visualizaciones). No se descargan vídeos ajenos.

No recopilamos datos de los espectadores, salvo las estadísticas agregadas que cada plataforma muestra al propietario del canal.

4. Almacenamiento

Todo se guarda únicamente en el ordenador Windows del propietario; no hay servidores ni bases de datos en la nube. Los tokens y las credenciales se cifran con DPAPI de Windows, se guardan en una carpeta con acceso restringido y nunca se registran ni se muestran.

5. Cesión

No vendemos, alquilamos ni compartimos datos de usuarios de TikTok ni otros datos personales. Tampoco los usamos para publicidad, perfiles ni entrenamiento de IA.

6. Conservación y borrado

Los tokens se conservan mientras la cuenta esté conectada. Desconectarla en la App borra los archivos locales. El acceso también puede revocarse desde TikTok (sección de permisos de apps, en Ajustes y privacidad) o desde la cuenta de Google.

7. Este sitio web

Es un sitio estático alojado en GitHub Pages, sin cookies, analítica, anuncios ni formularios. GitHub puede tratar datos técnicos, como la IP, según su declaración de privacidad.

8. Menores

La App y este sitio no están dirigidos a menores y no recopilamos sus datos de forma consciente.

9. Seguridad

Aplicamos las medidas descritas: almacenamiento local, cifrado con DPAPI, permisos de carpeta restringidos y permisos mínimos. Ningún sistema garantiza una seguridad absoluta.

10. Cambios y contacto

Actualizaremos esta página y su fecha antes de cambiar el uso de los datos. Para consultas: contactar con LeonidaLoop.
